# База знаний RAG

JSONL-файлы этой папки загружаются стратегией `rag` (`app/nlp/rag.py`). Одна строка — один документ:

```json
{"id": "zh-zhuxi-lisao-01", "language": "zh", "kind": "commentary", "title": "Чжу Си о строке …", "text": "…", "source": "朱熹《楚辭集注》, издание …, с. …", "always": false}
```

- `language`: `zh`, `kk` или `any`; `kind`: `guideline`, `commentary`, `lexicon`, `example`.
- `always: true` — документ входит в каждый промпт (процедура MIP/MIPVU, правила проекта).
- `source` обязателен: указывать издание и страницу. Цитаты комментариев сверять с изданием.
- Записи с пометкой «сводка команды» требуют библиографической ссылки перед публикацией.
