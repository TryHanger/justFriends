# Тестовая библиотека

Эти тексты скачаны из открытых источников и предназначены только для локальной проверки загрузки и анализа.

- `chinese_tang_poems.txt` — китайский классический корпус «唐詩三百首» (唐代/清代 compilation), источник: [Wikisource](https://zh.wikisource.org/wiki/唐詩三百首). Оригинальные произведения находятся в общественном достоянии; текст Wikisource распространяется по условиям, указанным на странице источника.
- `abai_zhazgytury.txt` — стихотворение Абая Құнанбайұлы «Жазғытұры», источник: [Wikisource](https://wikisource.org/wiki/Жазғытұры), лицензия источника указана на странице Wikisource.

Загрузка через интерфейс: открыть «Библиотека», выбрать файл, указать язык и нажать «Загрузить и проанализировать».
