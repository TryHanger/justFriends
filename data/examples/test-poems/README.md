# Тестовые поэтические тексты

Файлы `.txt` содержат тексты для быстрой проверки загрузки и анализа через веб-интерфейс.

- `chinese_jingyesi.txt` — Ли Бай, «静夜思» («Мысли в тихую ночь»), вариант текста из раздела 《唐诗三百首》 на Wikisource. Источник: https://zh.wikisource.org/zh-hans/靜夜思
- `kazakh_gylym_tappai_maktanba.txt` — Абай Құнанбайұлы, начальный фрагмент стихотворения «Ғылым таппай мақтанба». Источник: https://wikisource.org/wiki/Ғылым_таппай_мақтанба

Оба файла — UTF-8 plain text. Авторские оригиналы являются историческими произведениями; при повторном использовании сохраняйте указание автора и сверяйте требования к конкретной транскрипции/изданию и применимое право.
