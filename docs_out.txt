Задания к практической работе № 1–2
Задание 1. Формирование набора данных о стандартах
Выберите не менее 10 международных и национальных стандартов, относящихся к программному обеспечению и системной инженерии. В перечне должны быть представлены стандарты ISO, IEC, IEEE, совместные стандарты ISO/IEC/IEEE и национальные стандарты.
Для каждого стандарта необходимо указать:
обозначение стандарта;
организацию(-и)-разработчика(-ов);
название;
область применения;
назначение;
пример практического использования.
Создайте на языке Python структуру данных для хранения собранной информации.
Результат: программа должна выводить сформированный перечень стандартов в структурированном виде.

Задание 2. Табличный анализ стандартов
На основе созданного набора данных разработайте программу, которая:
преобразует сведения о стандартах в табличную форму;
выводит общее количество стандартов;
определяет количество стандартов каждой организации;
группирует стандарты по организациям;
позволяет отобрать стандарты по заданной области применения;
определяет количество различных областей применения стандартов.
Для выполнения задания используйте библиотеку pandas.
Результат: таблица данных о стандартах и результаты группировки и фильтрации данных.

Задание 3. Сравнительный анализ международных и национальных стандартов
Проведите сравнительный анализ стандартов ISO, IEC, IEEE, совместных стандартов ISO/IEC/IEEE и национальных стандартов.
Для каждой группы определите:
основное назначение;
основные области применения;
примеры стандартов;
возможное применение в программной и системной инженерии.
Результаты представьте в виде сравнительной таблицы.
На основе таблицы сформулируйте вывод о различиях между международными и национальными стандартами.

Задание 4. Разработка программы поиска стандартов
Разработайте на Python программу для поиска стандартов по ключевому слову.
Поиск должен выполняться по следующим полям набора данных:
обозначение стандарта;
область применения;
назначение.
Программа должна:
принимать ключевое слово от пользователя;
выполнять поиск по набору данных;
выводить найденные стандарты;
выводить сообщение, если соответствующие стандарты отсутствуют.
Проверьте работу программы минимум на трёх различных поисковых запросах.
Результат: работающая программа поиска и результаты её тестирования.

Задание 5. Визуализация данных о стандартах
Разработайте программу визуализации собранных данных.
Необходимо построить:
диаграмму распределения стандартов по организациям;
диаграмму распределения стандартов по областям применения.
Для построения диаграмм используйте библиотеку matplotlib.
Диаграммы должны содержать:
название;
подписи осей;
читаемые обозначения категорий.
На основе визуализации ответьте:
Какая организация представлена наибольшим количеством стандартов?
Какие области применения встречаются чаще всего?
Можно ли по выбранным 10 стандартам сделать общий вывод о распространённости стандартов? Обоснуйте ответ.

Задание 6. Выбор стандартов для программного проекта
Рассмотрите ситуацию.
Разрабатывается информационная система университета. При разработке необходимо учитывать следующие направления:

качество программного обеспечения;

управление рисками.
Разработайте на Python программу, позволяющую сопоставить выбранные стандарты с указанными направлениями.
Программа должна:
представить соответствие между стандартами и областями программной инженерии в структурированном виде;
определить, какие стандарты относятся к каждой области;
определить области, которые охватываются несколькими стандартами;
определить области, представленные наименьшим количеством стандартов;
представить результаты в табличной или графической форме.
На основе результатов программы:
выберите не менее трёх стандартов, которые целесообразно использовать в рассматриваемом проекте;
объясните назначение каждого выбранного стандарта;
укажите, какую инженерную задачу проекта он поддерживает;
объясните, почему при разработке одной программной системы могут использоваться несколько стандартов.
Результат: разработанная программа, результаты анализа и обоснованный выбор стандартов для проекта.

Задания к практической работе № 3–4
Тема: Моделирование жизненного цикла программного обеспечения в соответствии со стандартом ISO/IEC 12207. Анализ процессов системной инженерии по ISO/IEC 15288
Цель работы: исследовать процессы жизненного цикла программного обеспечения и системной инженерии, научиться моделировать их взаимосвязи, выявлять нарушения выполнения проекта, анализировать последствия изменений и оценивать готовность программной системы к эксплуатации с использованием Python.

Задание 1. Моделирование жизненного цикла программного проекта
Рассмотрите проект разработки информационной системы университета.
Система должна обеспечивать:
авторизацию пользователей; 
управление данными студентов; 
управление дисциплинами; 
выставление оценок; 
формирование отчётов; 
разграничение прав доступа. 
Необходимо самостоятельно разработать Python-программу, моделирующую основные работы жизненного цикла данного проекта.
В программной модели должно быть представлено не менее 8 взаимосвязанных процессов жизненного цикла, включая процессы, связанные с определением требований, проектированием, разработкой, интеграцией, проверкой, валидацией, эксплуатацией и сопровождением.
Для каждого элемента модели необходимо предусмотреть информацию о:
названии; 
ответственном; 
входных данных; 
результате; 
состоянии выполнения; 
связи с другими процессами. 
Программа должна позволять получить общую картину текущего состояния проекта.
Результат: программная модель жизненного цикла выбранной системы.

Задание 2. Проверка правильности выполнения процессов
В реальном проекте процессы могут выполняться с нарушением установленной логики.
Рассмотрите следующие ситуации:
разработка начата до завершения анализа требований; 
интеграция выполнена до завершения разработки одного из модулей; 
проверка программного продукта отсутствует; 
система передана пользователям до проведения валидации; 
один из обязательных результатов процесса отсутствует. 
Разработайте программу, которая автоматически анализирует состояние проекта и обнаруживает такие нарушения.
Студент должен самостоятельно определить не менее пяти правил контроля жизненного цикла.
Для каждого найденного нарушения программа должна:
определить проблемный процесс; 
указать причину; 
определить уровень серьёзности проблемы; 
сформировать понятное сообщение пользователю. 
Результат: автоматизированная проверка корректности выполнения жизненного цикла.

Задание 3. Моделирование зависимостей между процессами
Линейная последовательность процессов не всегда правильно отражает реальный проект. Несколько работ могут выполняться параллельно, а результаты одного процесса могут использоваться сразу в нескольких последующих процессах.
Разработайте на Python модель зависимостей между процессами проекта.
Программа должна определять:
с каких процессов может начинаться проект; 
какие процессы являются конечными; 
какие процессы зависят друг от друга; 
существуют ли изолированные процессы; 
какие процессы имеют наибольшее количество входящих и исходящих зависимостей;
существует ли полный маршрут от определения требований до эксплуатации; 
Дополнительно: определите, какие процессы являются наиболее значимыми для сохранения целостности маршрута, и обоснуйте свой выбор. Объясните, почему графовая модель жизненного цикла может быть полезнее простой последовательности процессов.
Представьте полученные зависимости в удобной форме.
Дополнительно: объясните, почему графовая модель жизненного цикла может быть полезнее простой последовательности этапов.
Результат: программная модель связей между процессами.

Новое требование:

программная реализация;

интеграция. 
Валидация системы ещё не проводилась.
Разработайте программу, которая определяет, какие элементы проекта могут быть затронуты изменением требования.
Программа должна выявить:
какие проектные решения требуют пересмотра;

Маршрут влияния изменения студент должен определить программно на основе связей между элементами проекта.
Результат: автоматизированный анализ влияния изменения требования.

Задание 5. Анализ процессов программного и системного уровней
Разделите работы рассматриваемого проекта на три группы:
